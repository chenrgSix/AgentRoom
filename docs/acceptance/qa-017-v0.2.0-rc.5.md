## Delivered Scope

The release source inherits owner-configured local Pi permissions, preserves
existing Pi command arguments, and streams safe resumable output from Pi,
managed Codex, and Generic Runtime adapters. The central Web surface renders
Markdown, presents a compact Discussion and Run hierarchy, parses exact Agent
and reserved `@all` commands, and exposes recoverable current-Room archival.
The authoritative task evidence is recorded by `BRG-023`, `RUN-007`, `WEB-029`
through `WEB-034`, and `QA-016` in `docs/TASKS.md`.
