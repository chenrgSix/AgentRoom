# QA-058 ConveneWire v0.5.0 Release Candidate

Status: release goal frozen before repair, tag creation or publication on
2026-09-03. Delivery state lives only in `docs/TASKS.md`.

## Goal

Publish one immutable `v0.5.0-rc.3` prerelease containing the completed
Governed Software-Team Execution Core and its bounded-autonomy Web surface.
The first `v0.5.0-rc.1` and `v0.5.0-rc.2` candidates are retained as
unpublished zero-asset failed-closed records. The replacement candidate must
pass exact-source CI,
native packaging, Central OCI
execution, closed-asset verification and an independent credential-free public
download. It does not replace stable Latest `v0.4.2`.

## Release Scope

The candidate includes the unreleased source since `v0.4.2`:

- client-owner pairing and scoped Team/Room browser entry;
- approved execution Plans, deterministic graph scheduling, explicit retry and
  scheduler controls;
- owner-local governed Runtime, isolated worktrees, independent verification,
  exact-target integration and proof-gated dependency inputs;
- source evidence, gate proof, explicit adoption and semantic reuse contracts;
- Plan supersession, exact local evidence carry-forward and bounded Tech Lead
  delegation;
- focused Discussion participation, opt-in read-only quorum sealing and
  content-free late-evidence audit;
- Plan, Evidence and bounded-autonomy browser control surfaces; and
- run-scoped temporary roots and invocation-scoped Go/npm caches with physical
  success, failure, timeout, cancellation and parallel cleanup evidence.

Repository paths, Git remotes, Git/SSH credentials, worktrees and Git commands
remain Client/Bridge authority under explicit Owner-local grants. Central owns
Plan, scheduling, authorization, evidence/proof/adoption and operation receipt
facts; it does not acquire repository or credential authority.

The existing Remote Evidence implementation is shipped only as an optional,
credential-free-by-default extension. No GitHub/GitLab adapter, PR lifecycle,
webhook, push, remote merge or provider-credential Web UI is admitted by this
release.

## Upgrade Boundary

Stable `v0.4.2` contains migrations through `0055`. This candidate contains
the additive migration history through `0086`. Operators must take a verified
Central backup before upgrade and retain the matching `v0.4.2` packages and
secrets. Rollback means restoring that pre-upgrade database with the matching
old release; old binaries must not run against an upgraded database.

Bridge protocol version `1.0`, existing Device and Agent identities and the
canonical `convenewire://` plus bounded legacy `agentroom://` handlers remain.
Central, Web and Bridge from this candidate should be installed together for
the new governed-execution workflow.

## Admission Gates

Publication requires all of the following:

1. `OPS-014` aligns the Central OCI verifier and Linux regression on one
   fail-closed cleanup contract, with focused and full Go verification;
2. the exact candidate commit passes Repository, Go, native macOS Desktop and
   native Windows Desktop main CI;
3. an annotated `v0.5.0-rc.3` tag resolves to that immutable commit and an
   empty prerelease Draft exists for the same tag;
4. every protected Release workflow job checks out that resolved SHA;
5. native Windows installs stable `v0.4.2`, upgrades in place to the candidate,
   preserves representative Owner state and verifies install, ZIP, staging,
   protocol registration and uninstall ownership;
6. both Linux Central OCI architectures pass clean-daemon load, default Server
   readiness/build identity and Caddy execution, and all four Central archives
   consume their matching once-built bundle;
7. the exact 22 assets pass the tagged verifier before upload and after a fresh
   authenticated Draft download;
8. the Draft is published as a prerelease, remains distinct from Latest, and a
   separate credential-free directory downloads and verifies all 22 public
   assets with the tagged verifier; and
9. `SITE-003` updates only post-publication README/site release copy, passes
   static/build/docs gates and proves the public Pages bytes match the exact
   deployed source.

Failed or ambiguous gates authorize no tag movement, asset replacement,
publication, skipped assertion or completion claim. Temporary downloads and
build caches must be task-owned and physically removed after verification.

## Explicit Exclusions

This prerelease does not close `BRG-013`, `WEB-050` or `QA-038`. It does not
claim macOS login-restart acceptance, exhaustive Hosted-Agent production
browser states, a paid/live model provider, multiple physical execution
machines, signed or notarized packages, automatic updates, production
deployment, new Remote Forge integrations or stable-release admission.

[33750886209](https://github.com/chenrgSix/ConveneWire/actions/runs/33750886209)

Central packaging, upload and Release verification jobs were skipped, and the
Draft retained zero assets.

The tag is immutable and the Draft remains unpublished. `OPS-015` owns the
artifact-assembly correction and a package-export regression. After that fix
passes exact-source main CI, this same release line must use a new annotated RC
tag; `v0.5.0-rc.1` is never moved, replaced or published.

## OPS-015 Repair Evidence

The final runtime stage now copies the owned Contracts `src` directory beside
its package manifest and generated validators. The regression derives every
conditional `.mjs` default export from `packages/contracts/package.json`,
confirms that the target exists and requires the Docker runtime stage to copy
that exact file or an ancestor directory. This protects the missing
`execution-validation` export and future runtime exports without weakening the
real clean-daemon Release gate.

The focused export/verifier tests and the complete controller suite pass. Go
vet, the controller build, the 354-file documentation gate and whitespace
checks pass. Each Go invocation used a distinct owned `convene-wire-test-run-*`
root and physically removed it on exit.
