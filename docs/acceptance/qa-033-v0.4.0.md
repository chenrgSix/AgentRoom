# QA-033: ConveneWire v0.4.0

## Admission decision

The Owner authorized a packaged macOS smoke as the final interactive gate for
publishing `v0.4.0` as the stable Latest release. This is a release-admission
decision, not a replacement for the schema-v4 two-physical-machine contract.
At stable publication, `QA-002`, `QA-028`, and `QA-030` therefore remained
`BLOCKED` until one fresh reviewed schema-v4 record bound their required
Windows Device, connection, heartbeat, Run, metrics, canonical deep-link, TLS,
and human-review evidence. The later
[2026-08-30 schema-v4 record](evidence/qa-002-20260830-schema-v4.md) closes those
separate gates without changing this historical stable admission decision.

The tested product code is the exact `v0.4.0-qa031.1` candidate at
`32de89e882938eb045e884ada71b018068ae4f9e`. Changes on `main` after that tag and
before this admission record are documentation plus a test-only WebSocket close
handshake stabilization; no shipped Server, Web, contract, controller, Bridge,
Desktop, installer, or packaging implementation changed.

## Explicit boundary

Central and Bridge ran on the same physical Mac. This record therefore does
not assert two-machine routing, physical Windows canonical-link launch,
schema-v4 capture-window completeness, metrics-to-heartbeat temporal binding,
or the schema-v4 human-review receipt. It cannot close `QA-002`, `QA-028`, or
`QA-030`, even though the overlapping same-host product behavior passed.

The release remains unsigned, unnotarized, manual-update-only, and intended for
trusted small Teams.
