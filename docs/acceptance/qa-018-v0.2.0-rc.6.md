## Delivered Scope

The release source treats expired Runs as terminal for reversible lifecycle
controls, adds revision-safe Room collaboration settings, and enforces exact
Agent and reserved `@all` commands at the Server. Agent reply handoffs persist a
recoverable routing intent before dispatch. Bridge connection settings can
replace the central URL and HTTPS trust without replacing Agents or Device
credentials. A deployment may additionally configure a central Server Token;
Bridge passes it on join, claim, legacy pair, and WebSocket requests while the
Console exposes only whether the Token is configured.

The authoritative task evidence is recorded by `ROOM-006`, `ROOM-007`,
`BRG-024`, and `BRG-025` in `docs/TASKS.md`.
