# QA-047: ConveneWire v0.4.2

Date: 2026-08-31. The Owner explicitly replaced the initial transition-prerelease
plan with publication of **v0.4.2 stable**. No v0.5.0-rc.1 tag or Release was
created. This stable release gets a new tag and Draft; it does not promote or
overwrite a historical candidate. Delivery state lives only in `docs/TASKS.md`.

## Admission boundary

The release includes the optional Hosted Agent, product experience and Bridge
audit work since `v0.4.1`, including `RUN-017` at `4b81737`. The most recent
targeted repair passed two full 346-test Server runs, contract/schema/build
checks and six deterministic E2E scenarios. Those local results do not replace
exact-source CI or native release-package evidence.

Publication requires:

1. an exact commit that passes Repository, Go, native macOS and native Windows
   main CI;
2. an annotated `v0.4.2` tag naming that commit and an empty non-prerelease Draft;
3. the protected Release workflow checking out that one SHA for all jobs;
4. native Windows `v0.4.1`-to-`v0.4.2` install/upgrade/uninstall verification,
   preserved owner state and installed/staging/ZIP executable identity;
5. both immutable Central OCI architectures passing clean-daemon execution and
   all four matching Central archives with independent internal-checksum pins;
6. the exact 22 assets passing the tagged verifier before upload, after Draft
   download, and in a separate clean authenticated local download;
7. publication as a non-prerelease, followed by a fresh anonymous download and the
   same tagged verifier; and
8. public stable Latest resolving to `v0.4.2`.

Failed or ambiguous gates do not authorize publication, tag movement, asset
replacement, skipped assertions or claims of successful acceptance.

## Pre-tag gate repairs

Main CI [33353830099](https://github.com/chenrgSix/ConveneWire/actions/runs/33353830099)
for `6f3674e` failed in Go and Windows; Repository and macOS passed. No tag or
Draft was created for that failing source. The retained failure prompted:

- `QA-048`: three cancellation connection tests now wait for callback completion
  before asserting durable fence removal. Receiving the terminal frame occurs
  before the sender returns and clears the fence. Production ordering and all
  identity/state/no-Runtime assertions remain unchanged. Each focused test
  passed 100 repetitions; full connection and delivery race tests passed.
- `BRG-068`: original SVG rendering reproduced different PNGs on local arm64 and
  executed amd64, with 64 differing pixels. Disabling rasterx fused multiply-add
  under pinned Go 1.26.7 made all three resources byte-identical without changing
  the authoritative SVG. The isolated tool and its CI/package callers now pin
  that arithmetic. A checked-in-byte test runs in arm64 and Windows CI, with
  existing ICO, alias, geometry, security and actual-PE tests retained. Local
  arm64 race/vet and amd64 tool tests, visual inspection and 31 packaging/policy
  tests passed. Omitting the arithmetic pin on arm64 fails the new byte-comparison
  test, confirming that it detects the original defect. These local executions
  do not stand in for native Windows CI.

Fresh exact-source CI and every package/publication gate above remain required.

The next Windows runs passed canonical icon checks, then exposed the existing
workflow-failure fixture's exit-code scope bug. Diagnostic CI
[33355002136](https://github.com/chenrgSix/ConveneWire/actions/runs/33355002136)
confirmed that the zero-exit stub was invoked once but still triggered the
nonzero guard. `QA-049` reads the exact child `Process.ExitCode`, checks the
expected value, waits with a bound and disposes the process, rather than copying
an ambient `LASTEXITCODE` shadowed by an earlier injection. All eleven actual
workflow guards pass both exit 23 and exit 0 locally, with eight production path
cases and 32 policy tests. Native Windows completion is still required before
release admission; no production Bridge behavior changes in this fixture repair.

CI [33355173576](https://github.com/chenrgSix/ConveneWire/actions/runs/33355173576)
passed Repository, Go and macOS, and the Windows icon, exit-injection,
silent-WebView2 and output-path checks. It then exposed an unreachable
fixture-only pause branch in the native activation test: message `0x8002` was
nested inside a decoder that only handles `WM_COPYDATA` (74). `QA-050` handles
fixture control before invoking that decoder. Pairing, wake, legacy behavior,
receiver rejection and the actual 50-ms unresponsive-window negative remain;
the test deadline is not widened and timeout diagnostics name the awaited event.
A portable ordering regression and Windows test cross-build supplement, but do
not replace, the subsequent native run. The production interceptor is unchanged.

## Explicit exclusions

The open `WEB-050`, `QA-038` and `BRG-013` criteria are not marked complete by
this stable release. In particular, this does not substitute for exhaustive Hosted
browser-state acceptance, live-provider production approval, physical desktop
activation or macOS login-restart acceptance. Existing historical physical
records are not reused as evidence for newly versioned stable binaries.

No production deployment, user database, existing application, platform trust
store or model credential is changed during this release procedure. Only
repository commits, the newly named tag/Draft and its protected build workflow
are in scope. Existing published and historical Draft assets are preserved.
