## Pre-Publication Defects Closed

The local release preflight found that the Server WebSocket Trace ID validator
still required the first base64url suffix character to be alphanumeric even
though the authoritative Schema and Go Bridge correctly allow leading `-` and
`_`. Randomly generated valid IDs therefore produced an intermittent
`run.accepted` rejection. Commit `61ab1f0` aligned both Trace and safe-log
validation with the contract, added deterministic positive and negative cases,
and made the fixture report an unexpected socket close directly instead of
waiting for a generic timeout.

The first tag-pinned Release run
[32878613208](https://github.com/chenrgSix/AgentRoom/actions/runs/32878613208)
built all seven archives but stopped before upload because the verifier's exact
`strings` line check rejected the shorter stable version embedded next to Go
string-table bytes. No asset entered the draft Release. Commit `77c11bf`
changed the check to require an exact version suffix boundary: it accepts the
embedded stable `v0.2.0` value but cannot accept `v0.2.0-rc.6` or another longer
version as the stable tag.

After the correction passed an 11-asset rehearsal and exact-source CI, the
still-private zero-asset draft and its old tag were removed with explicit user
approval. The annotated `v0.2.0` tag was recreated once on final commit
`77c11bf`. The earlier source commit remains in Git history, while no old
Release asset or public version was overwritten.
