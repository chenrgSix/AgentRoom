## Release Workflow

The first dispatch,
[32638605994](https://github.com/chenrgSix/AgentRoom/actions/runs/32638605994),
failed safely during draft preflight because the validation job had read-only
release permissions. No build or publication job ran. Commit `3f7bbdc` granted
write access only to the jobs that inspect the draft, while build and test jobs
remain read-only.

The replacement dispatch,
[32638769625](https://github.com/chenrgSix/AgentRoom/actions/runs/32638769625),
passed Bridge tests, five CLI builds, both native macOS GUI builds, pre-upload
asset verification, draft upload, and post-upload verification. The draft was
then published as a prerelease; the tag remained at the recorded source commit.

This proves a tag-pinned, empty-draft, no-clobber workflow. It does not claim
server-enforced Release or tag immutability; that requires a separate GitHub
repository rule.

## Independent Asset Verification

`bridge/scripts/verify-release-assets.sh`. The verifier reported 11 valid

layouts, launchers, executable modes, architectures, GUI bundle metadata, and
