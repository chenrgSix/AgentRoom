## Continuous Integration

[32682564398](https://github.com/chenrgSix/AgentRoom/actions/runs/32682564398)
passed on the exact tagged commit. Its Repository, Go, and Desktop macOS jobs
validated schemas, Node builds/tests, deterministic E2E, maintained Markdown,

release scripts, and Desktop-tagged tests/vet/build.

The preceding run
[32682078630](https://github.com/chenrgSix/AgentRoom/actions/runs/32682078630)
failed safely before a tag existed. It exposed Linux shell descendants keeping
Runtime pipes open past a caller deadline and an undersized clean-runner E2E
startup window. The release source terminates Unix Runtime process groups,
bounds all platform waits, adds a direct regression and Windows compile check,
and records bounded Bridge stage and exit diagnostics for future failures.
