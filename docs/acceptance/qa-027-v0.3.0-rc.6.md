  provisioning UI share one version. A Bridge must also be upgraded before it

  physical Windows machine, including pinned-certificate connection, installer
  behavior, tray interaction, and a live Codex launch.
- `BRG-013` remains active until a real macOS logout/login or restart proves
  exactly one desktop instance without credentials in the LaunchAgent.
- `QA-002` remains ready until two physical machines produce reviewed online
  and offline/reconnect Codex Runs.
- Packages remain unsigned, unnotarized, and manual-update-only.
- `v0.2.0` remains the stable Latest release while this version is evaluated as
  a prerelease candidate.
