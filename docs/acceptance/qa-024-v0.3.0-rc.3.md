## Independent Public Asset Verification

A fresh directory at `/tmp/agentroom-v030rc3-public-assets` downloaded the
published prerelease. The tagged verifier ran in an Ubuntu 24.04 container and
reported `Verified 13 release assets for v0.3.0-rc.3`. It rechecked all nine
binary archives/installers, checksums, safe archive layout, launchers,
architectures, embedded versions, GUI and installer metadata, and licenses.

The same download initially exposed a host-tool portability issue on macOS:
BSD `strings` does not support GNU `strings -el`. Commit `b3df622` adds a
semantics-preserving Python UTF-16LE fallback without changing the release
assets or acceptance criteria. The complete 13-asset public verification then
also passed directly on macOS.
