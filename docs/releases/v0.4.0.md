# ConveneWire v0.4.0

ConveneWire v0.4.0 is the stable trusted-small-Team release for self-hosted
Central, browser collaboration, and managed Codex/Pi Bridge execution. It is
the first stable release under the ConveneWire product, repository, package,
binary, installer, and release-asset identities.

## Highlights

- Adds one-install Central lifecycle control with checksum-pinned packages,
  backup, restore, upgrade, rollback-safe trust rotation, and private-hostname
  migration.
- Makes public CA the deployment default while canonical one-time
  `convenewire://` Device pairing can bootstrap exact-origin scoped private
  trust without installing a system CA or copying credentials.
- Ships portable Bridge CLI packages, native macOS Desktop packages, a Windows
  Desktop portable package, and a Windows current-user installer.
- Supports durable offline delivery, same-Device reconnect recovery, managed
  Codex/Pi execution, Task-scoped Runtime continuity, and bounded safe Runtime
  output and activity.
- Adds the versioned Task/Run/Result work model, immutable review/evidence,
  Team Workbench, Artifact publication/materialization, and guarded handoffs.
- Uses ConveneWire naming for current product surfaces while retaining the
  explicitly bounded legacy wire, installation, data, metric, bundle, and URL
  identities required for safe upgrades.

## Upgrade and compatibility notes

- Upgrade Central, Web, contracts, controller, and Bridge from the same tag.
  Back up Central before upgrade and retain the matching rollback package and
  database backup.
- Existing installation IDs, SQLite names, owner data/configuration paths,
  Compose identity, macOS bundle ID, Windows installer AppId, and selected
  legacy wire tokens intentionally remain compatible under ADR-0024.
- New deployments use `CONVENE_WIRE_*` configuration. Released
  `AGENT_ROOM_*` variables remain bounded aliases; conflicting current and
  legacy values fail closed.
- New Device links use `convenewire://`; the Desktop client continues accepting
  `agentroom://` only for existing links and in-place upgrade compatibility.
- macOS and Windows Desktop packages are unsigned, macOS is not notarized, and
  updates remain manual. Verify `SHA256SUMS` before executing a download; never
  disable TLS or operating-system security globally.

## Supported scope and remaining evidence

The stable scope is trusted small Teams. It does not claim public
internet-scale identity, high availability, signed/notarized distribution,
automatic updates, or universal environment certification.

The owner-authorized packaged macOS gate passed canonical pairing, scoped
private trust, a real Codex self-test, one offline/reconnect Run, and one online
Run. Because Central and Bridge were on the same physical Mac, this evidence
does not close the separate schema-v4 two-physical-machine tasks `QA-002`,
`QA-028`, or `QA-030`. Those remain visible post-release gates.
