# ConveneWire v0.4.0-qa031.1 Draft

This unpublished QA candidate is the first closed release matrix after the
current product, package, repository, deep-link and deployment identities moved
to ConveneWire. It packages the schema-v4 physical-acceptance verifier and the
Windows Runtime no-console implementation for the next two-machine run.

## Admission boundary

This evidence closes `GOV-016`: current distribution uses the canonical
ConveneWire repository and asset identities, while the protected matrix proves
the renamed native Windows installer can upgrade without losing owner state.
Stable legacy wire tokens, installation identity and data paths remain
compatibility boundaries rather than partially renamed authorities.

The Release remains an unpublished Draft. No public prerelease or stable
release was created. Automated Windows process and installer evidence does not
prove physical window-manager behavior. `BRG-046` still requires one installed
Windows Desktop Codex Run that streams and terminates normally without opening
an empty console. `QA-002`, `QA-028`, and `QA-030` still require one reviewed
schema-v4 record from the same physical Device, including a canonical
`convenewire://` launch and the required TLS attestations.

The packages remain unsigned, unnotarized, and manual-update-only.
