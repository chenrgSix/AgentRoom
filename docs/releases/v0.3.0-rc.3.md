# AgentRoom v0.3.0-rc.3

This release candidate adds the first Windows amd64 Desktop Bridge packages:
the existing portable ZIP and a new per-user installer.

## Highlights

- Adds the native Windows Desktop Bridge with the existing Overview, Local
  Agents, Settings, usage guide, tray, close-to-tray, and single-instance
  behavior.
- Adds an Inno Setup installer that installs under
  `%LOCALAPPDATA%\Programs\AgentRoom Bridge` without requesting administrator
  privileges.
- Registers a Start menu shortcut and current-user Windows uninstaller, offers
  an unchecked desktop shortcut, and uses a stable application identity for
  in-place upgrades.
- Keeps `%APPDATA%\agentroom` configuration outside installer ownership so an
  upgrade or uninstall does not remove owner state.
- Detects the system Microsoft Edge WebView2 Runtime. If it is absent, the
  installer warns the user and can open Microsoft's official download page;
  it does not download or execute Runtime code itself.
- Retains the Windows portable ZIP for users who prefer a no-install preview.

## Upgrade and Compatibility Notes

- Upgrade the central Server, Web UI, contracts, and Bridge from the same tag.
  This candidate has no new central database migration.
- The Windows Desktop package targets Windows 10 or newer on amd64/x64
  compatible systems and requires the system WebView2 Runtime.
- The installer wizard is English. The installed Bridge UI remains Chinese.
- Closing or replacing a running Bridge uses Windows Restart Manager, but the
  installer does not automatically relaunch the application after an upgrade.
- The Windows installer and portable ZIP, like the macOS Desktop archives, are
  intentionally unsigned. Verify `SHA256SUMS`; do not disable SmartScreen,
  Defender, or Gatekeeper globally.
- Automatic updates and Windows login startup remain unsupported.
- Back up the central SQLite database and local Bridge configuration before
  upgrading. Version-aligned rollback may require restoring the matching
  database backup after migration.

## Artifacts

The Release workflow publishes five portable CLI archives, two native macOS
Desktop ZIPs, one Windows Desktop portable ZIP, one Windows per-user installer,
`SHA256SUMS`, `LICENSE`, `NOTICE`, and `COMMERCIAL-LICENSE.md`. The committed
verifier requires exactly 13 assets and checks their names, checksums, archive
paths, architectures, embedded versions, GUI metadata, installer metadata,
launchers, and licenses before and after upload.

## Remaining Gates

- Human testing on a physical Windows machine remains separate from native CI,
  including SmartScreen, wizard layout, tray interaction, and missing-WebView2
  presentation.
- `BRG-013` still requires a real macOS logout/login or restart proving exactly
  one desktop instance and no credential stored in the LaunchAgent.
- `QA-002` still requires reviewed online and offline/reconnect evidence from
  two physical machines.
- Packages remain unsigned, unnotarized, and manual-update-only.
- `v0.2.0` remains the stable Latest release while this candidate is evaluated.
