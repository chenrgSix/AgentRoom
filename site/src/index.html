中央 Agent

只想先聊起来？配置模型即可开始。

在中央服务启动后，由 Owner 在网页填写模型名称与 API Key，选择允许进入的 Room。无需为它另装服务、客户端或 Runtime。

  • 中央服务直接调用 OpenAI Responses API
  • API Key 加密保存在现有数据库
  • 不配置，也不影响其他 Agent 使用

能力边界 仅远程模型调用，不操作电脑，不读写文件，不执行命令。

本机 Agent

需要动手做事？连接你的工作电脑。

通过 Bridge 接入本机 Codex 或 pi。让已有的 Runtime 使用自己的工作区和工具，中央服务负责协调与记录。

  • 在执行工作的电脑安装 Bridge
  • 配对 Device，再配置 Runtime 与工作区
  • 执行遵循本机审批、沙箱与权限策略

能力边界 取决于本机 Runtime 的配置；配对不代表获得无限电脑权限。

A FEW THINGS TO KNOW

开始之前，你可能想问。

中央 Agent 是不是还要额外部署一个 Agent 服务？

不需要。当前源码中的中央 Agent 是中央服务自带的 HTTP 调用能力。启动中央服务后，Owner 在网页上选配即可；不用再安装 pi、Codex 或单独的 Agent 容器。不配置也能继续使用本机和演示 Agent。

支持哪些模型服务？

中央 Agent 当前仅支持固定的 OpenAI Responses API。模型名称由你配置，需要对应的可用凭据与权限；不支持任意兼容 API 地址。验证与运行可能产生提供方用量。本机 Agent 则使用自己配置的 Runtime。

自托管意味着所有数据都不会离开服务器吗？

不是。Team 记录存储在你的中央服务中，但远程模型调用会把获授权的上下文发送给模型提供方，本机 Runtime 也可能调用其模型服务。请按数据要求选择接入方式并配置房间与 Runtime 权限。

下载稳定版就能用到页面上的全部功能吗？

稳定 Latest 仍为 v0.4.2；v0.5.0-rc.6 是当前预发布版，新增客户端 Owner 入口、受控软件团队执行 Core、可信局域网免证书访问、精简的 12 资产分发和 Discussion 进度完整性修复。评估 RC 前请阅读迁移与回滚说明并备份 Central；真实模型调用仍需自行配置受支持的服务和凭据。官网上线本身不代表应用发版。

局域网里的另一台电脑还要安装证书吗？

不一定。可信局域网部署可为浏览器明确选择 HTTP，Windows、macOS 或 Linux 都无需安装 CA；Bridge、Device 与执行流量仍走单独固定的 HTTPS 通道。只有选择私有 HTTPS 时，浏览器才需要信任私有 CA，配对后的 Bridge/Desktop 会在“设置”里提供带指纹校验的高级信任引导，并且不会静默修改系统信任。公网部署应使用公共 CA。

ConveneWire 会接管我的 Git 仓库和 SSH Key 吗？

不会。ConveneWire 不接管你的 Git 仓库或 Git 凭据。仓库路径、Git/SSH 凭据、worktree 和 Git 操作由本地 Client/Bridge 控制；Central 只协调 Plan、调度、授权、证据与操作回执。

一个人、一台电脑也能用吗？

可以把中央服务与 Bridge 放在同一台适用的电脑上；如果只需要中央 HTTP Agent，则无需 Bridge。当前中央发布包支持 Linux 和 macOS；客户端 Bridge 可在支持的平台上单独连接。
